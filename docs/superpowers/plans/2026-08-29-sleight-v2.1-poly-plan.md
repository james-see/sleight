# Sleight v2.1: Per-Finger Polyphony Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend Sleight from monophonic Theremin to a 4-voice polyphonic instrument where each finger plays an independent note with its own per-note pitch bend, using the MPE/UMP multi-channel infrastructure already in v2.0.

**Architecture:** Add a `ChannelAllocator` to `MIDISource` that maps voice slots to MPE channels (2–5), extend `MIDIEvent.Kind` with a default-channel field for per-event channel routing, extend `UMPEncoder` to honor that channel in MPE mode, and add a `PolyPads` instrument that maps each extended finger to a voice. Settings + UI gains an instrument picker.

**Tech Stack:** Swift 5.10, CoreMIDI (UMP + MIDI 1.1), Vision (21 landmarks), XCTest, XcodeGen. Same as v2.0.

```swift
public enum ChannelMode {
    case ump
    case mpe(maxVoices: Int)   // channels 2..(1+maxVoices), voice 0→ch2, voice 1→ch3, etc.
    case legacy                 // always channel 0 (monophonic)
}

public struct ChannelAllocator {
    public init(mode: ChannelMode)
    /// Allocate a channel for a voice that is starting. Steal oldest if all slots full.
    public mutating func noteOn(voice: Int) -> UInt8
    /// Release the channel for this voice.
    public mutating func noteOff(voice: Int)
    /// Current channel for a voice (or 0 if not sounding).
    public func channel(for voice: Int) -> UInt8
    /// Release all voices; called on mode change / instrument switch.
    public mutating func reset()
}
```

**MPE channel mapping:** voice 0 → channel 1 (nibble 1 = "MIDI ch 2"), voice 1 → channel 2 (nibble 2 = "ch 3"), etc. Global CC always goes on channel 0 (nibble 0 = "ch 1").

```swift
import Foundation

/// Maps voice slots to MPE channel indices for multi-note expression.
///
/// - UMP mode: always channel 0 (per-note management is by note number in the
///   64-bit message; no channel routing needed).
/// - MPE mode: voice 0 → channel 1 (nibble 1 = MIDI ch 2), voice 1 → channel 2,
///   etc. Channel 0 (nibble 0) is reserved for global CC.
/// - Legacy mode: always channel 0 (monophonic, last-note priority).
public enum ChannelMode {
    case ump
    case mpe(maxVoices: Int)
    case legacy
}

public struct ChannelAllocator {
    private let mode: ChannelMode
    /// voice → channel nibble (1..maxVoices+1 for MPE, 0 for UMP/legacy)
    private var voiceChannels: [Int: UInt8] = [:]

    public init(mode: ChannelMode) {
        self.mode = mode
    }

    /// Allocate a channel for a voice that is starting. If the voice already
    /// has a channel, returns the existing one (no double-allocation).
    @discardableResult
    public mutating func noteOn(voice: Int) -> UInt8 {
        switch mode {
        case .ump, .legacy:
            return 0
        case .mpe(let maxVoices):
            if let existing = voiceChannels[voice] { return existing }
            // Find the lowest free channel in 1..maxVoices (nibbles 1..maxVoices)
            let used = Set(voiceChannels.values)
            for ch in 1...UInt8(maxVoices) {
                if !used.contains(ch) {
                    voiceChannels[voice] = ch
                    return ch
                }
            }
            // All slots full — steal voice 0's channel (shouldn't happen in
            // practice with 4 fingers / 4 slots, but safe).
            voiceChannels[voice] = 1
            return 1
        }
    }

    public mutating func noteOff(voice: Int) {
        voiceChannels.removeValue(forKey: voice)
    }

    /// Current channel nibble for a voice (0 if not sounding).
    public func channel(for voice: Int) -> UInt8 {
        switch mode {
        case .ump, .legacy: return 0
        case .mpe: return voiceChannels[voice] ?? 0
        }
    }

    /// Release all voices. Call on mode change or instrument switch.
    public mutating func reset() {
        voiceChannels.removeAll()
    }
}
```

The current `encodeMPE` hardcodes channel 1 (nibble 1). v2.1's poly needs channels 1–4 (nibbles for MIDI ch 2–5).

```swift
private func encodeMPE(_ e: MIDIEvent) -> [UInt32] {
    switch e.kind {
    case let .noteOn(let note, let velocity, let channel):
        let ch = channel == 0 ? UInt32(1) : channel   // default → nibble 1 (MIDI ch 2)
        return [midi1(MIDICVStatus.noteOn.rawValue, ch, UInt32(note) << 8 | midi1Velocity(velocity))]
    case let .noteOff(let note, let channel):
        let ch = channel == 0 ? UInt32(1) : channel
        return [midi1(MIDICVStatus.noteOff.rawValue, ch, UInt32(note) << 8)]
    case let .perNotePitchBendSemitones(_, let semis, let channel):
        let ch = channel == 0 ? UInt32(1) : channel
        return [midi1(MIDICVStatus.pitchBend.rawValue, ch, midi1BendData(semis: semis))]
    case let .cc(controller, value):
        // CC is always global (channel 0 / nibble 0)
        return [midi1(MIDICVStatus.controlChange.rawValue, 0, UInt32(controller) << 8 | UInt32(value))]
    }
}
```

**Design summary:**
- Right hand fingers: index (tip=8, MCP=5), middle (tip=12, MCP=9), ring (tip=16, MCP=13), little (tip=20, MCP=17).
- Each finger is a voice (0–3). Finger Y position within the pitch band → scale-quantized note. Finger extension (angle at MCP) → gate. Raw finger Y → per-note bend. Finger extension depth → velocity.
- Left hand: shared volume (CC7), same as Theremin.
- `PolyPads` owns a `ChannelAllocator` — but wait: the allocator lives in `MIDISource`. The instrument doesn't know the MPE mode. Solution: the instrument emits events **without** channels (default 0), and `MIDISource.send()` routes through its allocator. The allocator key is the **finger index** (voice 0–3), matching the channel field.

Actually, revisiting: the instrument emits events, then `MIDISource` looks at note-on/note-off to allocate channels. But the instrument emits `noteOn(note:, channel: 0)` by default. The source needs to know which voice this note belongs to to allocate the right channel.

**Resolution:** The instrument assigns voice numbers (0–3) and the source's allocator maps voice → channel. But `MIDIEvent` doesn't carry a voice number. Options:
1. Add voice to MIDIEvent — too invasive.
2. Have the instrument talk to the source directly — breaks the protocol.
3. **Channel allocator per-finger via note number**: since each finger quantizes to a different pitch (different Y), the note numbers are distinct, so the allocator can key on note number instead of voice number. But two fingers could theoretically land on the same note (same scale degree, same octave) — unlikely with 4 fingers spanning 2 octaves but possible.

**Cleaner approach:** Keep the `ChannelAllocator` voice-based, but have the instrument emit events with the channel pre-set. The instrument owns its own allocator (or a simpler channel-tracking dict). The `MIDIEvent.channel` field carries it through to the encoder. The source's allocator is only for mode-change reset.

Wait — actually the simplest correct approach: **the instrument assigns channels directly** using its own lightweight voice→channel mapping, and sets `channel` on each event. The `MIDISource` just passes events through to the encoder. The `ChannelAllocator` in the source becomes a mode-aware factory that tells the instrument which channels to use.

**Revised flow:**
1. `SleightController.applySettings()` creates a `ChannelMode` and passes it to both the instrument (for channel assignment) and the source (for mode-based encoding).
2. `PolyPads` has its own `voiceChannels: [Int: UInt8]` mapping (voice 0 → channel 1, voice 1 → channel 2, etc.).
3. `MIDIEvent` events carry the channel from the instrument.
4. `MIDISource.send()` passes events to `encoder.encode()` which honors the channel.
5. `MIDISource` doesn't need its own allocator for the send path — the instrument handles it. The source's allocator is removed.

This is cleaner: the instrument owns voice management, the encoder owns word layout, the source just transmits. Let me revise the spec:

**Revised Task 2/3/4 interface:**
- `ChannelMode` stays (passed from settings to instrument + source).
- `ChannelAllocator` becomes a helper the instrument can use: `ChannelAllocator.channels(for mode:) -> [UInt8: UInt8]` or simpler, the instrument just computes `channel = voiceIndex + 1` for MPE, 0 for UMP/legacy.
- No allocator in `MIDISource` — just configure the encoder mode.

Let me simplify: the instrument computes channels. For MPE: voice 0 → ch 1, voice 1 → ch 2, etc. For UMP/legacy: always ch 0. The instrument knows its mode (passed at construction). No `ChannelAllocator` needed in the source.

But Task 2 already wrote `ChannelAllocator`... Let me keep it as a pure utility the instrument uses, and also keep it simple. The instrument initializes a `ChannelAllocator` with the current mode and calls `noteOn(voice:)` / `noteOff(voice:)` to get channels.

**Final design:**
- `PolyPads` owns a `ChannelAllocator`.
- On finger extension (gate on): `let ch = allocator.noteOn(voice: fingerIndex)`, emit `.noteOn(note:, velocity:, channel: ch)`.
- On finger retraction (gate off): `allocator.noteOff(voice: fingerIndex)`, emit `.noteOff(note:, channel: ch)`.
- Per-note bend: `allocator.channel(for: fingerIndex)` → emit bend with that channel.
- CC7: always channel 0 (global).

This keeps `ChannelAllocator` as the shared channel-mapping utility, used by the instrument. The source doesn't need it. Let me update the spec accordingly — but since the plan is written, I'll note this correction in the PolyPads implementation section.

```swift
import Foundation

/// v2.1 poly instrument: each extended finger is an independent voice.
/// Right hand finger Y → pitch (quantized), finger extension → gate,
/// raw finger Y → per-note bend. Left hand → shared volume (CC7).
public final class PolyPads: Instrument {
    public var id: String { "poly-pads" }
    public var displayName: String { "Poly Pads" }

    // MARK: Configuration (mirrors Theremin)
    public var pitchBand: ClosedRange<Double> = 0.55...0.95
    public var volumeBand: ClosedRange<Double> = 0.1...0.7
    public var scale: Scale = .minorPentatonic
    public var root: Int = 60
    public var octaves: Double = 2
    public var glideMode: GlideMode = .glide
    public var defaultVolume: UInt8 = 100

    // MARK: MIDI mode + channel allocation
    public var midiMode: MIDIMode = .mpe
    private var allocator: ChannelAllocator {
        ChannelAllocator(mode: channelMode)
    }
    private var channelMode: ChannelMode {
        switch midiMode {
        case .ump: return .ump
        case .mpe: return .mpe(maxVoices: 4)
        case .legacy: return .legacy
        }
    }

    /// Finger tip → voice index mapping (right hand only).
    private static let fingerTips: [Int] = [Landmark.indexTip, Landmark.middleTip, Landmark.ringTip, Landmark.littleTip]
    private static let fingerMCPs: [Int] = [Landmark.indexMCP, Landmark.middleMCP, Landmark.ringMCP, Landmark.littleMCP]

    // MARK: State
    private var voiceStates: [Int: VoiceState] = [:]  // voiceIndex → state
    private var lastVolume: UInt8 = 0

    private struct VoiceState {
        var note: UInt8
        var baseNote: UInt8
        var channel: UInt8
        var rawPitch: Double
    }

    public init() {}

    public func update(hands: [HandFrame], dt: Double) -> [MIDIEvent] {
        var events: [MIDIEvent] = []
        let t = CACurrentMediaTime()

        let right = hands.first { $0.side == .right }
        let left = hands.first { $0.side == .left }

        // ---- per-finger pitch + gate ----
        if let r = right, let pitchRange = pitchBandRemapped(hand: r) {
            for voiceIdx in 0..<Self.fingerTips.count {
                let tipIdx = Self.fingerTips[voiceIdx]
                let mcpIdx = Self.fingerMCPs[voiceIdx]
                let tipY = r.points[tipIdx].y
                let mcpY = r.points[mcpIdx].y

                // Gate: finger extension. Extended if tip is noticeably above MCP.
                let extensionAmount = mcpY - tipY  // positive = extended
                let threshold: Double = 0.05  // 5% of normalized height
                let isExtended = extensionAmount > threshold

                if isExtended {
                    // Map tip Y to pitch within the band
                    let yNorm = min(max((tipY - pitchRange.lowerBound) / (pitchRange.upperBound - pitchRange.lowerBound), 0), 1)
                    let raw = Double(root) + (1 - yNorm) * 12 * octaves  // inverted: high finger = low note
                    let pitch = MusicTheory.quantize(raw, scale: scale, root: root % 12)
                    let baseNote = UInt8(pitch.rounded())

                    if voiceStates[voiceIdx] == nil {
                        // Note on
                        let ch = allocator.noteOn(voice: voiceIdx)
                        let vel = polyVelocity(extension: extensionAmount)
                        events.append(MIDIEvent(kind: .noteOn(note: baseNote, velocity: vel, channel: ch), timestamp: t))
                        voiceStates[voiceIdx] = VoiceState(note: baseNote, baseNote: baseNote, channel: ch, rawPitch: raw)
                    } else if let state = voiceStates[voiceIdx] {
                        // Update existing voice: re-articulate if changed note (stepped), or bend (glide)
                        if glideMode == .stepped && baseNote != state.baseNote {
                            events.append(MIDIEvent(kind: .noteOff(note: state.note, channel: state.channel), timestamp: t))
                            let ch = allocator.noteOn(voice: voiceIdx)
                            let vel = polyVelocity(extension: extensionAmount)
                            events.append(MIDIEvent(kind: .noteOn(note: baseNote, velocity: vel, channel: ch), timestamp: t))
                            voiceStates[voiceIdx] = VoiceState(note: baseNote, baseNote: baseNote, channel: ch, rawPitch: raw)
                        } else {
                            // Glide: continuous bend from raw position
                            let bend = (raw - Double(state.baseNote))
                            events.append(MIDIEvent(kind: .perNotePitchBendSemitones(note: state.note, bend, channel: state.channel), timestamp: t))
                            voiceStates[voiceIdx]?.rawPitch = raw
                        }
                    }
                } else {
                    // Finger retracted — note off
                    if let state = voiceStates[voiceIdx] {
                        allocator.noteOff(voice: voiceIdx)
                        events.append(MIDIEvent(kind: .noteOff(note: state.note, channel: state.channel), timestamp: t))
                        if glideMode == .glide {
                            events.append(MIDIEvent(kind: .perNotePitchBendSemitones(note: state.note, 0, channel: state.channel), timestamp: t))
                        }
                        voiceStates.removeValue(forKey: voiceIdx)
                    }
                }
            }
        }

        // ---- volume (left hand Y, shared) ----
        var volume: UInt8
        var belowFloor = false
        if let l = left {
            let y = l.points[Landmark.wrist].y
            if y <= volumeBand.lowerBound { volume = 127 }
            else if y >= volumeBand.upperBound { volume = 0; belowFloor = true }
            else {
                let n = 1 - (y - volumeBand.lowerBound) / (volumeBand.upperBound - volumeBand.lowerBound)
                volume = UInt8((n * 127).rounded())
            }
            lastVolume = volume
        } else {
            volume = lastVolume == 0 ? defaultVolume : lastVolume
        }

        // Volume floor releases all notes
        if belowFloor && !voiceStates.isEmpty {
            for (voiceIdx, state) in voiceStates {
                allocator.noteOff(voice: voiceIdx)
                events.append(MIDIEvent(kind: .noteOff(note: state.note, channel: state.channel), timestamp: t))
                if glideMode == .glide {
                    events.append(MIDIEvent(kind: .perNotePitchBendSemitones(note: state.note, 0, channel: state.channel), timestamp: t))
                }
            }
            voiceStates.removeAll()
        }

        // Emit CC7 volume to global channel (0) when it changes
        if belowFloor {
            events.append(MIDIEvent(kind: .cc(7, 0), timestamp: t))
            lastVolume = 0
        } else {
            events.append(MIDIEvent(kind: .cc(7, volume), timestamp: t))
        }

        return events
    }

    /// Velocity from finger extension depth (fully extended = 1.0).
    private func polyVelocity(extension: Double) -> Double {
        let clamped = min(max(`extension` / 0.15, 0), 1)  // normalize: 0.15 = full extension
        return 0.3 + clamped * 0.7  // range 0.3..1.0
    }

    /// Remap pitch band using index-tip Y (same logic as Theremin).
    private func pitchBandRemapped(hand: HandFrame) -> ClosedRange<Double>? {
        // Use the right hand's pitchBand (x-based in Theremin, but for fingers
        // we repurpose it as the Y range). Actually: PolyPads uses finger Y for
        // pitch, so the pitch band should be a Y range. We reuse pitchBand's
        // semantics by treating it as the vertical pitch zone.
        // For simplicity: pitch band 0.55...0.95 applies to Y position of
        // finger tips, same range as Theremin's X band.
        guard let _ = hand.points[Landmark.indexTip].y else { return nil }
        return pitchBand
    }
}
```


```markdown
Extend your fingers to play — each finger controls an independent note. Finger vertical position maps to pitch (quantized to your scale), finger extension depth maps to velocity. Move a held finger vertically for continuous per-note pitch bend (glide). The left hand still controls volume (CC7).
```
